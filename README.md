# Крестики-нолики на C++

Консольная игра для двух игроков. Программа проверяет ходы и определяет победу или ничью.

## Сборка

Откройте `TicTacToe/TicTacToe.vcxproj` в Visual Studio с компонентом «Разработка классических приложений на C++». Для сборки из командной строки Visual Studio выполните из корня проекта следующую команду.

```powershell
msbuild TicTacToe/TicTacToe.vcxproj /p:Configuration=Release
```

## Правила

Первым ходит X. Введите номер свободной клетки от 1 до 9. Номера расположены как на цифровой клавиатуре.

```text
7 8 9
4 5 6
1 2 3
```
